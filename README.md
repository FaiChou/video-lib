# 片刻 · 视频收藏

无需构建的单页视频库。前端是原生 HTML、CSS、JavaScript；后端使用 Node.js 读取目录、播放和保存上传文件，并通过 Mediabunny 与 `@mediabunny/server` 检查编码、转换视频。无需数据库。

## Debian 部署

使用 Node.js 22+，以 root 按 [Debian 部署教程](DEPLOY_DEBIAN.md) 安装 `deploy/video-library.service`，即可后台运行、开机自启及异常重启。服务使用 root 运行，直接使用程序默认值，无需创建额外的系统用户或环境配置文件。

## 手动启动

需要 Node.js 22 或更新版本及 npm。首次启动或更新代码后，进入本项目目录安装锁定版本的依赖，再启动服务：

```sh
npm ci
node server.mjs
```

本机打开 **http://127.0.0.1:8876**；在局域网中的其他设备上，打开 **http://nuc8.local:8876** 或使用服务器的局域网 IPv4 地址。按 `Ctrl+C` 停止服务。

安装完成后，也可以运行 `npm start`。`@mediabunny/server` 通过 NodeAV 使用原生编解码器；`npm ci` 会按当前系统下载预编译依赖及安装程序附带的工具，需要联网。无需手动安装或调用 FFmpeg 命令。请在实际运行服务的电脑上安装依赖，不要复制其他操作系统的 `node_modules/`。

读取项目文件夹、上传并保存文件需要本地服务，因此请通过这个地址访问，不要直接双击 `public/index.html`。

## 放入素材

把截图中的 `selena`、`granada` 等用户文件夹整体放进项目的 `videos` 文件夹：

```text
video-library/
├── server.mjs
├── media-converter.mjs
├── package.json
├── package-lock.json
├── public/
├── videos/
│   ├── selena/
│   │   ├── 20260813_60.mp4
│   │   └── 20261005_1.mp4
│   └── granada/
│       └── 20260816_旅行.mp4
├── deploy/
│   └── video-library.service
├── DEPLOY_DEBIAN.md
└── README.md
```

复制完成后点击页面的刷新按钮，即可读取最新内容。只读取用户名目录下的直接视频文件，不递归读取更深层级；忽略隐藏文件、符号链接和其他文件格式。交付目录不含演示视频。

## 浏览

- 默认按文件名中的日期从新到旧排列，可切换从旧到新。
- 用户标签支持多选；再点一次取消，点击「全部用户」清除用户筛选。
- 支持文件名搜索，默认每页 48 个视频，可按 48 的倍数递增，最多每页 480 个。
- 电脑端默认「一行 6 个」，可在列表右上角切换为「一行 4 个」查看更大的卡片；实际列数随浏览器宽度调整，手机端保持双列布局。
- 勾选工具栏的「隐藏已处理」，只显示未处理的视频，可与用户、搜索条件组合使用；保存为已处理后会自动从当前列表隐藏，展开的播放器保持打开。
- 筛选、排序、搜索、页码、每页数量和列数设置保存在地址栏，刷新可保留。
- 点击视频预览图或文件名打开播放器，支持拖动进度、全屏和音量控制。
- 列表卡片左下角和展开播放器底部都有「未处理 / 已处理」开关，点击可切换，两处状态同步；保存失败时会提示并保留原状态。
- 卡片右下角显示文件体积和「下载」按钮。
- 点击「下载」时快速检查素材编码；已有 H.264 视频、AAC 音频（或无音频）的 MP4，以及已有转换缓存的素材直接开始下载，不进入转码队列，也不弹出准备窗口。
- 只有需要转换的素材才排队并显示转换进度；弹窗中仍可选择「下载原文件」。
- 卡片只加载可见区域附近的视频预览，分页切换会释放旧的视频资源。

### 处理状态

状态保存在素材目录下的 `videos/.processed.json`，首次标记时自动创建，刷新页面或重启服务后仍会保留。所有访问这台服务的电脑共用这些状态，其他已打开的页面点击刷新即可读取最新状态。格式如下：

```json
{
  "selena/20260813_60.mp4": true,
  "granada/20260816_旅行.mp4": false
}
```

`true` 表示已处理，`false` 或没有记录表示未处理。记录按“用户文件夹/视频文件名”关联，移动或重命名视频后会视为新的视频。备份素材时请同时保留此 JSON 文件；若需手动编辑，请先停止服务。

## 管理和删除

点击右上角「上传视频」右侧的管理图标进入管理页，也可直接访问 `/manage`。

- 列表不加载缩略图，显示名字、分组、时间、大小、是否已处理和删除操作；点击视频名字可打开播放器预览。分组对应用户文件夹，时间沿用视频库的日期规则。
- 支持按文件名搜索、按分组和处理状态筛选、时间排序及分页。
- 可逐行勾选视频，表头复选框用于全选或取消选择当前页。翻页、排序和调整每页数量会保留选择；修改搜索、分组或处理状态筛选会清空选择，也可点击「取消选择」清空。
- 点击某一行的「删除」可删除单个视频；选择多个视频后点击「批量删除」，核对数量及分组、文件名列表，再确认删除。执行时会显示进度。
- 删除会永久移除服务器上的视频文件及对应处理记录，清理当前下载缓存，保留分组文件夹。
- 视频正在进行下载编码检查或转换时，需等待完成后再删除。批量删除中成功的项目会从列表移除；失败的项目保留选择并显示具体原因，可只重试剩余失败项。

## 上传

点击右上角「上传视频」打开上传弹窗。独立上传页仍可通过 `/upload` 访问；点击左上角图标返回视频库。

1. 选择已有用户；或者点击「新建用户」，输入用户名后点击「创建」。用户名就是磁盘文件夹名称。
2. 选择一个或多个视频，也可以把视频拖入弹窗中的虚线区域。
3. 检查每个视频右侧的日期，可以逐个调整。
4. 点击上传。每个视频会显示上传进度、编码检查或转换状态及保存结果；部分失败时，保留成功结果，只重试失败项。

上传支持 `.mp4`、`.webm`、`.mov`、`.m4v`，默认单文件最大 2 GiB。文件先上传到服务器，再读取实际视频和音频编码。H.264 + AAC（或无音频）的 MP4 跳过转换；VP9 等不兼容编码转换为 H.264 视频、AAC 音频的 MP4，完成后保存到 `videos/所选用户/`。转换后的文件使用 `.mp4` 扩展名。

上传批次按顺序处理，服务器同时只执行一个转换任务，其他转换任务显示等待；兼容素材及已有缓存的下载不受转码队列影响。传输达到 100% 后，可能还需等待服务器检查或转换完成；看到保存成功才算入库。转换在服务器完成，浏览器无需缓存整段视频，局域网 HTTP 地址仍可使用。

### 日期和重名规则

| 上传文件                        | 最终名称                                 |
| ------------------------------- | ---------------------------------------- |
| `20260813_clip.mp4`             | 保留 `20260813_clip.mp4`                 |
| `clip.mp4`                      | `当天日期_clip.mp4`                      |
| `20260230_clip.mp4`（日期无效） | `当天日期_clip.mp4`                      |
| 手动将日期改成 2026-10-20       | `20261020_clip.mp4`                      |
| 同名文件已存在                  | 自动添加 `_2`、`_3` 等后缀，不覆盖原文件 |

表中的 MP4 示例假定内容已兼容；需要转换的 WebM、MOV、M4V 最终扩展名统一为 `.mp4`，同名编号规则不变。

日期前缀格式为 `YYYYMMDD_`，默认时区是 `Asia/Shanghai`。直接复制到素材目录的旧文件若没有有效日期前缀，按文件修改日期展示，不修改文件名；通过上传弹窗提交的新文件会自动补齐日期。

## 默认配置

安装依赖后即可启动，无需创建或加载环境配置文件。

| 项目 | 默认值 |
| ---- | ------ |
| 监听地址 | `0.0.0.0`（所有 IPv4 网卡） |
| 端口 | `8876` |
| 允许访问的地址 | `nuc8.local`、本机地址和服务器网卡 IP |
| 素材目录 | 项目目录下的 `videos/` |
| 日期时区 | `Asia/Shanghai` |
| 单文件上传上限 | 2 GiB（2147483648 字节） |
| 下载转换缓存 | `videos/.transcoded/` |
| 缓存保留时间 | 7 天未使用后，在准备新的下载任务时清理 |

部署在局域网中的 Debian 服务器后，可直接访问 **http://nuc8.local:8876**，无需额外配置。若服务器启用了防火墙，需允许局域网访问 TCP 8876 端口。当前版本没有登录鉴权，能访问的人都能浏览、下载、上传和删除。

## 格式兼容

浏览器是否能播放取决于视频编码，文件扩展名并不保证兼容。服务实际检查轨道编码，目标格式为 H.264 视频、AAC 音频的 MP4；没有音轨的视频保持无音轨。已兼容的 MP4 不重复编码，避免额外画质损失。

通过网页上传的新素材在入库前完成检查和必要转换。直接复制到目录或以前上传的旧素材，在下载时检查；需要转换的文件生成到 `videos/.transcoded/`，后续下载和服务重启后都可复用缓存。7 天未使用的缓存会在准备新的下载任务时清理。已有素材原件及其处理状态保持不变，网页播放仍读取原件；需要保留原始编码时使用「下载原文件」。

服务使用 CPU 软件编解码，关闭 GPU 自动探测，无需安装 CUDA 或 VAAPI 驱动。转换耗时取决于视频时长、分辨率和服务器性能，并会占用服务器 CPU 和磁盘空间。转换失败会显示错误提示，详细原因可查看服务器日志；旧素材可重试或下载原文件。缓存可在停止服务后删除，下次下载会重新生成。

服务端转换使用 [Mediabunny 的 NodeAV 扩展](https://mediabunny.dev/guide/extensions/server)，无需浏览器的 WebCodecs 或 HTTPS 环境。原生依赖的安装和平台支持见 [NodeAV 文档](https://github.com/seydx/node-av)。

## 项目文件

- `server.mjs`：目录扫描、文件流、Range 播放、上传下载及删除接口、转换排队和下载缓存。
- `media-converter.mjs`：实际编码检测及 H.264/AAC MP4 转换。
- `public/index.html`：视频库、管理页、上传页及弹窗结构。
- `public/styles.css`：页面和移动端样式。
- `public/app.js`：筛选、排序、分页、播放、上传和管理删除交互。
- `videos/`：实际素材，用户名作为子目录。
- `tests/`：接口集成测试及真实媒体编码测试。
- `deploy/`：Debian systemd 服务文件。
- `DEPLOY_DEBIAN.md`：安装、开机自启、日志和升级教程。

安装依赖后运行 `npm test`。测试覆盖日期处理、同名保护、视频范围请求、下载、目录隔离、上传限制、中断清理、处理状态的持久化与并发保存、视频删除与缓存清理，以及使用真实媒体检查 VP9 转 H.264、音频兼容性和下载缓存。测试使用临时目录，不修改素材库。
