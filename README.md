# 片刻 · 视频收藏

无需构建的单页视频库。前端是原生 HTML、CSS、JavaScript；后端使用 Node.js 内置模块读取目录、播放和保存上传文件。没有第三方依赖，也没有数据库。

## Debian 部署

使用已有的 Node.js 20+，以 root 按 [Debian 部署教程](DEPLOY_DEBIAN.md) 安装 `deploy/video-library.service`，即可后台运行、开机自启及异常重启。服务使用 root 运行，直接使用程序默认值，无需创建额外的系统用户或环境配置文件。

## 手动启动

需要 Node.js 20 或更新版本。进入本项目目录，运行：

```sh
node server.mjs
```

本机打开 **http://127.0.0.1:8876**；在局域网中的其他设备上，打开 **http://nuc8.local:8876** 或使用服务器的局域网 IPv4 地址。按 `Ctrl+C` 停止服务。

也可以运行 `npm start`，不需要先执行 `npm install`。

读取项目文件夹、上传并保存文件需要本地服务，因此请通过这个地址访问，不要直接双击 `public/index.html`。

## 放入素材

把截图中的 `selena`、`granada` 等用户文件夹整体放进项目的 `videos` 文件夹：

```text
video-library/
├── server.mjs
├── public/
├── videos/
│   ├── selena/
│   │   ├── 20260813_60.mp4
│   │   └── 20261005_1.mp4
│   └── granada/
│       └── 20260816_旅行.mp4
├── deploy/
│   └── video-library.service
├── DEPLOY_DEBIAN.md
└── README.md
```

复制完成后点击页面的刷新按钮，即可读取最新内容。只读取用户名目录下的直接视频文件，不递归读取更深层级；忽略隐藏文件、符号链接和其他文件格式。交付目录不含演示视频。

## 浏览

- 默认按文件名中的日期从新到旧排列，可切换从旧到新。
- 用户标签支持多选；再点一次取消，点击「全部用户」清除用户筛选。
- 支持文件名搜索，默认每页 100 个视频，可切换为 50、100、200 或 500 个。
- 筛选、排序、搜索和页码保存在地址栏，刷新可保留。
- 点击视频卡片或「播放」打开播放器，支持拖动进度、全屏和音量控制。
- 列表卡片右上角和展开播放器底部都有「未处理 / 已处理」开关，点击可切换，两处状态同步；保存失败时会提示并保留原状态。
- 点击「下载」按浏览器下载设置保存到本地。
- 卡片只加载可见区域附近的视频预览，分页切换会释放旧的视频资源。

### 处理状态

状态保存在素材目录下的 `videos/.processed.json`，首次标记时自动创建，刷新页面或重启服务后仍会保留。所有访问这台服务的电脑共用这些状态，其他已打开的页面点击刷新即可读取最新状态。格式如下：

```json
{
  "selena/20260813_60.mp4": true,
  "granada/20260816_旅行.mp4": false
}
```

`true` 表示已处理，`false` 或没有记录表示未处理。记录按“用户文件夹/视频文件名”关联，移动或重命名视频后会视为新的视频。备份素材时请同时保留此 JSON 文件；若需手动编辑，请先停止服务。

## 上传

点击右上角「上传视频」打开上传弹窗。独立上传页仍可通过 `/upload` 访问；点击左上角图标返回视频库。

1. 选择已有用户；或者点击「新建用户」，输入用户名后点击「创建」。用户名就是磁盘文件夹名称。
2. 选择一个或多个视频，也可以把视频拖入弹窗中的虚线区域。
3. 检查每个视频右侧的日期，可以逐个调整。
4. 点击上传。每个视频会显示进度与结果；部分失败时，保留成功结果，只重试失败项。

上传支持 `.mp4`、`.webm`、`.mov`、`.m4v`，默认单文件最大 2 GiB。文件直接写入 `videos/所选用户/`，不会存到浏览器缓存中。

### 日期和重名规则

| 上传文件                        | 最终名称                                 |
| ------------------------------- | ---------------------------------------- |
| `20260813_clip.mp4`             | 保留 `20260813_clip.mp4`                 |
| `clip.mp4`                      | `当天日期_clip.mp4`                      |
| `20260230_clip.mp4`（日期无效） | `当天日期_clip.mp4`                      |
| 手动将日期改成 2026-10-20       | `20261020_clip.mp4`                      |
| 同名文件已存在                  | 自动添加 `_2`、`_3` 等后缀，不覆盖原文件 |

日期前缀格式为 `YYYYMMDD_`，默认时区是 `Asia/Shanghai`。直接复制到素材目录的旧文件若没有有效日期前缀，按文件修改日期展示，不修改文件名；通过上传弹窗提交的新文件会自动补齐日期。

## 默认配置

直接启动即可，无需创建或加载环境配置文件。

| 项目 | 默认值 |
| ---- | ------ |
| 监听地址 | `0.0.0.0`（所有 IPv4 网卡） |
| 端口 | `8876` |
| 允许访问的地址 | `nuc8.local`、本机地址和服务器网卡 IP |
| 素材目录 | 项目目录下的 `videos/` |
| 日期时区 | `Asia/Shanghai` |
| 单文件上传上限 | 2 GiB（2147483648 字节） |

部署在局域网中的 Debian 服务器后，可直接访问 **http://nuc8.local:8876**，无需额外配置。若服务器启用了防火墙，需允许局域网访问 TCP 8876 端口。当前版本没有登录鉴权，能访问的人都能浏览、下载和上传。

## 格式兼容

浏览器是否能播放取决于视频编码，文件扩展名并不保证兼容。H.264 + AAC 的 MP4 兼容性较好。浏览器无法解码的视频仍可下载到本地播放器观看。服务不自动转码，也不需要安装 FFmpeg。

## 项目文件

- `server.mjs`：目录扫描、文件流、Range 播放、上传和下载接口。
- `public/index.html`：视频库、上传页及弹窗结构。
- `public/styles.css`：页面和移动端样式。
- `public/app.js`：筛选、排序、分页、播放和上传交互。
- `videos/`：实际素材，用户名作为子目录。
- `tests/server.test.mjs`：接口集成测试。
- `deploy/`：Debian systemd 服务文件。
- `DEPLOY_DEBIAN.md`：安装、开机自启、日志和升级教程。

运行 `npm test` 可检查日期处理、同名保护、视频范围请求、下载、目录隔离、上传限制、中断清理，以及处理状态的持久化和并发保存。测试只使用临时目录。
